# 📺 DVD Rental System

Система видеопроката DVD-дисков с веб-интерфейсом.

> **Quick Start**: Запустите оба сервиса и откройте [https://localhost:3000](https://localhost:3000)

---

## 🚀 Быстрый старт (5 минут)

### Шаг 1: Запустите Laravel Backend

```bash
# Перейдите в папку backend
cd dvd-rental

# Установите зависимости (если нужно)
composer install

# Создайте файл .env (если нет)
cp .env.example .env

# Сгенерируйте ключ приложения
php artisan key:generate

# Настройте базу данных в .env:
# DB_CONNECTION=pgsql
# DB_HOST=127.0.0.1
# DB_PORT=5432
# DB_DATABASE=dvd_rental
# DB_USERNAME=postgres
# DB_PASSWORD=ваш_пароль

# Выполните миграции
php artisan migrate

# Запустите сервер
php artisan serve
```

✅ Backend запущен на `http://localhost:8000`

---

### Шаг 2: Запустите React Frontend

```bash
# Перейдите в папку frontend
cd dvd-rental-frontend

# Установите зависимости (если нужно)
npm install

# Запустите сервер
npm start
```

✅ Frontend запущен на `https://localhost:3000`

---

### Шаг 3: Зарегистрируйтесь и начните использовать!

Откройте [https://localhost:3000](https://localhost:3000) в браузере и зарегистрируйтесь.

### Что нужно установить:

| Компонент | Требование | Примечание |
|-----------|------------|------------|
| PHP | 8.1+ | Для Laravel backend |

## 🎮 Пошаговые сценарии использования

### Сценарий 1: Клиент бронирует DVD

1. **Зарегистрируйтесь** как `Client`
2. **Войдите** в систему
3. Перейдите в **"Фильмы"**
4. Найдите нужный фильм (поиск/фильтр)
5. Нажмите **"Подробнее"**
6. Выберите доступный DVD
7. Перейдите в **"Новое бронирование"**
8. Укажите даты и нажмите **"Создать бронирование"**

---

### Сценарий 2: Сотрудник выдаёт DVD

1. **Войдите** как `Employee`
2. Перейдите в **"Выдача"**
3. Выберите **пользователя** и **DVD**
4. Укажите **количество дней**
5. Нажмите **"Выдать DVD"**

---

### Сценарий 3: Сотрудник принимает возврат

1. Перейдите в **"Возврат"**
2. Выберите активную аренду
3. Нажмите **"Оформить возврат"**

---

### Сценарий 4: Администратор блокирует пользователя

1. **Войдите** как `Admin`
2. Перейдите в **"Панель"** → **"Блокировки"**
3. Нажмите **"+ Заблокировать пользователя"**
4. Выберите пользователя, укажите причину
5. Нажмите **"Заблокировать"**

## 🐛 Известные проблемы

| Проблема | Решение |
|----------|---------|
| Backend не запускается | Проверьте `php -v` и `composer -V` |
| Frontend не запускается | Проверьте `node -v` и `npm -v` |
| Ошибка подключения к БД | Проверьте параметры в `.env` |
| CORS ошибки | Убедитесь, что backend запущен на `localhost:8000` |
