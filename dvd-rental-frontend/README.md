## 🛠 Технологии

- **Frontend**: React 19, React Router 7, Axios
- **Backend**: Laravel (см. `dvd-rental` папка)
- **Сервер разработки**: `npm start` (https://localhost:3000)

## 📦 Установка и запуск

### Предварительные требования

- Node.js 20+
- npm 10+
- Laravel backend запущен на `http://localhost:8000`

### Шаги запуска

```bash
# Перейти в папку frontend
cd dvd-rental-frontend

# Установить зависимости (если еще не установлены)
npm install

# Запустить dev-сервер
npm start
```

Приложение откроется в браузере по адресу: **https://localhost:3000**

> ⚠️ Важно: Backend Laravel должен быть запущен и доступен по адресу `http://localhost:8000`

## 👥 Роли пользователей

| Роль | Права доступа |
|------|---------------|
| **client** | Просмотр фильмов, DVD; Создание бронирований; Просмотр своих аренд |
| **employee** | Все права клиента + Управление фильмами, жанрами, DVD; Бронирования и аренда; Выдача/возврат DVD |
| **admin** | Все права сотрудника + Управление пользователями, ролями, блокировками; Панель статистики |

## 🖥 Интерфейс

### 1. Страница входа (`/login`)
- Вход в систему
- Форма: email, пароль
- При успехе перенаправляет на главную страницу

### 2. Страница регистрации (`/register`)
- Регистрация нового пользователя
- Форма: имя, email, пароль (минимум 8 символов), телефон
- После регистрации автоматический вход

### 3. Главная страница (`/`)
- Приветственное сообщение
- Отображение текущего пользователя и его ролей

### 4. Каталог фильмов (`/movies`)
- Список всех фильмов с жанрами
- Поиск по названию
- Фильтрация по жанру
- Кнопка "Подробнее" для каждого фильма

### 5. Страница фильма (`/movies/:id`)
- Детальная информация о фильме
- Год выпуска, длительность, описание
- Список доступных DVD этого фильма

### 6. Список DVD (`/dvds`)
- Табличный список всех DVD
- Инвентарный номер, фильм, жанр, статус, цена за день

### 7. Для Клиента:

#### Мои бронирования (`/bookings`)
- Список бронирований текущего пользователя
- Период бронирования, статус
- Возможность отменить активное бронирование

#### Новое бронирование (`/bookings/new`)
- Выбор DVD из доступных
- Выбор дат начала и окончания
- Проверка доступности на выбранный период

#### Мои аренды (`/rentals`)
- Список аренд текущего пользователя
- Дата выдачи, дата возврата, стоимость

### 8. Для Сотрудника (доп. пункты в меню):

#### Управление фильмами (`/employee/movies`)
- Список всех фильмов
- Добавление нового фильма
- Редактирование существующего
- Удаление фильма

#### Управление жанрами (`/employee/genres`)
- Список всех жанров
- Добавление/редактирование/удаление жанра

#### Управление DVD (`/employee/dvds`)
- Список всех DVD
- Добавление нового DVD
- Редактирование существующего
- Удаление DVD

#### Бронирования (`/employee/bookings`)
- Список всех бронирований
- Изменение статуса (активное → отменено/завершено)

#### Аренда (`/employee/rentals`)
- Список всех аренд
- Просмотр детальной информации

#### Выдача DVD (`/employee/issue`)
- Выбор пользователя и DVD
- Выбор бронирования (опционально)
- Указание количества дней
- Оформление выдачи

#### Возврат DVD (`/employee/return`)
- Выбор активной аренды
- Оформление возврата

### 9. Для Администратора (доп. пункты в меню):

#### Панель администратора (`/admin/dashboard`)
- Статистика по системе:
  - Всего пользователей
  - Всего фильмов
  - Всего DVD
  - Активных аренд
  - Активных блокировок
- Общая информация о системе

#### Управление пользователями (`/admin/users`)
- Список всех пользователей
- Добавление нового пользователя
- Редактирование существующего
- Удаление пользователя
- Назначение/удаление ролей

#### Управление ролями (`/admin/roles`)
- Список всех ролей
- Добавление/редактирование/удаление роли

#### Управление блокировками (`/admin/blocks`)
- Список активных блокировок
- Создание блокировки (с указанием срока или без)
- Снятие блокировки

## 📖 Руководство по использованию

### Регистрация и вход

1. Перейдите на страницу `/register`
2. Заполните форму:
   - Имя (обязательное)
   - Email (обязательное)
   - Пароль (минимум 8 символов)
   - Телефон (опционально)
3. Нажмите "Зарегистрироваться"

### Создание ролей и пользователей (Администратор)

1. Войдите как администратор
2. Перейдите в "Панель" → "Роли"
3. Создайте роли: `client`, `employee`, `admin`
4. Перейдите в "Панель" → "Пользователи"
5. Создайте пользователей и назначьте им роли

### Просмотр фильмов и DVD (Клиент)

1. Войдите как клиент
2. Перейдите в "Фильмы"
3. Используйте поиск и фильтрацию для поиска нужного фильма
4. Нажмите "Подробнее" для просмотра детальной информации
5. Посмотрите доступные DVD

### Создание бронирования (Клиент)

1. Перейдите в "Новое бронирование"
2. Выберите DVD из списка
3. Выберите даты начала и окончания бронирования
4. Нажмите "Создать бронирование"

### Управление фильмами (Сотрудник)

1. Войдите как сотрудник
2. Перейдите в "Фильмы" (из меню сотрудника)
3. Нажмите "+ Добавить фильм"
4. Заполните форму:
   - Название (обязательное)
   - Описание (опционально)
   - Год выпуска
   - Длительность (в минутах)
   - Жанр (обязательный)
5. Нажмите "Добавить"

### Выдача DVD (Сотрудник)

1. Перейдите в "Выдача" (из меню сотрудника)
2. Выберите пользователя
3. Выберите DVD
4. Укажите количество дней
5. Нажмите "Выдать DVD"

### Возврат DVD (Сотрудник)

1. Перейдите в "Возврат" (из меню сотрудника)
2. Выберите активную аренду
3. Нажмите "Оформить возврат"

### Блокировка пользователя (Администратор)

1. Перейдите в "Панель" → "Блокировки"
2. Выберите пользователя
3. Укажите причину блокировки
4. (Опционально) Укажите срок окончания блокировки
5. Нажмите "Заблокировать"

## 🐛 Troubleshooting

### Страница загружается, но API запросы не работают

**Причина**: Backend Laravel не запущен или недоступен

**Решение**:
1. Убедитесь, что backend запущен: `cd dvd-rental && php artisan serve`
2. Проверьте, что backend доступен по адресу `http://localhost:8000`
3. Проверьте консоль браузера (F12) на наличие ошибок CORS

### Ошибка "Route [login] not defined"

**Причина**: Проблемы с конфигурацией Sanctum

**Решение**: Убедитесь, что middleware `auth:sanctum` настроен правильно в `routes/api.php`

### Данные не отображаются

**Причина**: Отсутствие прав доступа или ошибка аутентификации

**Решение**:
1. Проверьте, что вы вошли в систему
2. Убедитесь, что у вас есть необходимая роль для доступа к разделу
3. Проверьте консоль браузера на наличие ошибок

## 📝 Примечания

- Токены сохраняются в `localStorage` и действуют до выхода из системы
- Статусы DVD: `available`, `rented`, `reserved`, `unavailable`
- Статусы бронирования: `active`, `cancelled`, `completed`
- Статусы аренды: `active`, `returned`
- Система поддерживает конкурентное бронирование с блокировкой записей
- Блокировки могут быть постоянными (без `expires_at`) или временными
