# План разработки системы видеопроката DVD-дисков

## Этап 1: Подготовка окружения и база данных

### 1.1 Установка и настройка Laravel
- [ ] Установить PHP 8.1+
- [ ] Установить Composer
- [ ] Создать новый Laravel проект: `composer create-project laravel/laravel dvd-rental`
- [ ] Настроить переменные окружения (.env)
- [ ] Настроить подключение к PostgreSQL

### 1.2 Установка необходимых пакетов
- [ ] Установить Laravel Sanctum для аутентификации: `composer require laravel/sanctum`
- [ ] Опубликовать конфигурацию Sanctum: `php artisan vendor:publish --provider="Laravel\Sanctum\SanctumServiceProvider"`
- [ ] Установить CORS для API: `composer require fruitcake/laravel-cors`

### 1.3 Настройка базы данных
- [ ] Создать базу данных PostgreSQL
- [ ] Выполнить миграции: `php artisan migrate`
